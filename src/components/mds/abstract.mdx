# Abstract

随着深度学习模型的广泛应用，后门攻击对其安全性与可靠性构成严峻威胁。当前主流后门攻击方法大多采用易被人工审查识别的脏标签策略，而基于干净标签的新型攻击则展现出更强的隐蔽性。然而，在严格限制条件下构建高效干净标签攻击仍存在瓶颈。本文揭示了投毒过程中样本的选择策略对攻击有效性的关键影响，并提出一种基于特征对齐的新型干净标签攻击框架。该方法通过计算目标标签样本的特征质心，强制源标签样本在特征空间中向目标质心对齐，从而优化目标特征的语义表征能力，显著提升攻击成功率。在基准数据集上的多组对照实验表明，本方法在低投毒率、有限扰动预算等严格条件下性能优于现有的干净标签攻击方法，同时在实际场景中保持着对良性数据的高精度分类。此外，该方法对主流后门防御策略表现出强鲁棒性，证实了其潜在威胁强度。
